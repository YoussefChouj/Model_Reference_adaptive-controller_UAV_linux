Clamping & Back-Calculation, Built and Flagged

You now have two proper anti-windup mechanisms in the firmware — both behind a flag, both default OFF. This lesson is the map of what changed and how to prove it before it flies.

We added a per-loop switch aw_mode to every PID. It defaults to 0 (AW_LEGACY) via zero-initialisation, so every loop still behaves exactly as before until you opt one in. That is the mission rule satisfied: OFF = today, bit-for-bit.

What changed (two files)

  • robot_types.h — new enum PID_AntiWindup_e; two fields appended to PIDTypeDef: int aw_mode, float Kt. Appended, so the big positional initializer in pid.c zero-fills them.
  • pid.c — ComputePID() now branches on aw_mode. The else branch is the untouched legacy code.

The two new mechanisms, side by side

AW_CLAMP — freeze the integrator the instant the output really saturates AW_BACKCALC — let it integrate, then bleed it back by the saturation error

Clamp is parameter-free: integrate tentatively, and if U hit its limit while the error would push it further in, undo that tick's accumulation. Back-calc is smoother and tunable: it always integrates, then subtracts Kt·(U − U_presat) from the accumulator — zero when unsaturated, a pull-back when clipped. Full code on the reference card.

Watch this with back-calc Kt defaults to 0. With aw_mode = AW_BACKCALC and Kt = 0 you get pure always-integrate — worse than legacy. You must set Kt > 0. Start near Ki/Kp and sweep in sim.

Turn one loop on

// pitch rate loop → observer anti-windup   (gyroy = PITCH)
Ctrler.gyroyPID.aw_mode = AW_BACKCALC;
Ctrler.gyroyPID.Kt      = 0.002f;      // tune me

// roll rate loop → correct clamping        (gyrox = ROLL)
Ctrler.gyroxPID.aw_mode = AW_CLAMP;

Prove it before you fly it (mission rule 3)

Do not flip these on and take off. The test loop:

  1. Mirror the same branch in sim/'s RatePID (it's parity with ComputePID).
  2. Drive a saturating step — a setpoint big enough to peg U at UMax for a while.
  3. Plot the integrator SumE and the response for all three modes on one chart.
  4. You want to see: legacy holds a frozen sum and overshoots on release; clamp/back-calc keep the sum feasible and settle cleaner. If back-calc rings, lower Kt.
Your win You turned a diagnosis (Lesson 2: the gate is inert) into two real, flag-gated fixes — without touching the default flight path. That is the exact loop the whole mission repeats: understand → implement behind a flag → A/B in sim → then fly.
