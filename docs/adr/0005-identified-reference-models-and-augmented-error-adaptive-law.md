# 0005 - Identified Reference Models + Augmented-Error Adaptive Law

*   **Status:** Proposed (design sketch — config wired, code changes not yet applied)
*   **Date:** 2026-06-18
*   **Depends on:** ADR-0003 (inner-loop MRAC), ADR-0004 (SysID excitation), `docs/sysid_results.md`

## Context

SysID (2026-06-18) identified the three lateral rate plants:

| Axis | Identified plant | Relative degree | `ref_model_bw` |
| --- | --- | --- | --- |
| Roll | `165 / (s(1+s/19.8)) · e^{-15ms·s}` | **2** + delay | 44 rad/s |
| Pitch | `185 / (s(1+s/16)) · e^{-12ms·s}` | **2** + delay | 44 rad/s |
| Yaw | `37 / s` (pure integrator) | **1** | TBD (slow) |

The identified bandwidths are now wired into `mrac_config_*.ref_model_bw` (`API/mrac.c`). But two  
structural mismatches remain between the controller and the identified plants:

1.  **Reference-model type is global** (`mrac_flags.ref_model_type`). Roll/pitch want a **2nd-order**  
    reference (matching their relative-degree-2 dynamics); yaw wants a **1st-order** reference  
    (matching its relative-degree-1 integrator). One global type cannot serve both.
2.  **The adaptive law uses the raw tracking error** `**e = x − xm**`**.** For a relative-degree-2 plant the  
    error dynamics from `u_ad → e` are _not_ strictly positive real (SPR), so the standard Lyapunov  
    gradient `θ̇ = −Γ·P·B·e·Φ` is not guaranteed stable. Relative degree 1 (yaw) is fine as-is;  
    relative degree ≥ 2 (roll/pitch) needs an **augmented error**.

## Decision (proposed)

### 1\. Per-axis reference-model type

Move `ref_model_type` from `MRAC_FeatureFlags_t` (global) to `MRAC_AxisConfig_t` (per-axis):

```c
// MRAC_AxisConfig_t  (mrac.h)
uint8_t ref_model_type;   // 0 passthrough | 1 first-order | 2 second-order
```

Init: roll/pitch → `2`, yaw → `1`, Z → `1` (until identified). `MRAC_Control`'s `switch` reads  
`config->ref_model_type` instead of `mrac_flags.ref_model_type`. CMD `0x13` gains an axis index  
argument (or sets all four). Keeps passthrough (`0`) as the power-on default per axis for safety.

### 2\. Second-order reference model (already implemented, type 2)

`xm` is generated by `ẍm = wn²(r − xm) − 2ζ·wn·ẋm` with `wn = ref_model_bw = 44`, `ζ = 0.8`. This is  
in place in `MRAC_Control` case 2 and is the right reference for roll/pitch. No new code; just select  
it per axis (item 1).

### 3\. Augmented-error adaptive law for relative-degree-2 axes (roll/pitch)

For a relative-degree-2 reference `Wm(s) = wn² / (s² + 2ζwn·s + wn²)`, replace the raw error `e` in  
the weight update with the **augmented error** `ε`:

```
ε = e + (θᵀ ζ_f  −  [Wm·(θᵀΦ)])      // standard MIT/Narendra augmentation
```

where `ζ_f = Wm(s)[Φ]` is the regressor passed through the reference-model filter (one extra  
filtered-regressor state per basis component), and `Wm·(θᵀΦ)` is the adaptive signal passed through  
the same filter. The weight update becomes:

```
θ̇ = −Γ · ε · ζ_f / (1 + ζ_fᵀ ζ_f)        // normalized, SPR-restored
```

This restores SPR of the `u_ad → ε` map (Wm is SPR for the chosen wn, ζ), so the Lyapunov argument  
holds for relative degree 2. **Implementation cost:** one filtered copy of `Φ` per axis  
(`MAX_NUM_BASIS` extra states), the `Wm` filter on `θᵀΦ`, and swapping `e → ε`, `Φ → ζ_f` in the  
gradient. The delay (`12–15 ms`) is \< `1/wn` (`≈ 23 ms`) so it is absorbed as phase margin, not  
modelled explicitly; keep `wn = 44` (not higher) so the unmodelled delay stays inside the margin.

### 4\. Yaw stays relative-degree-1

Yaw (`37/s`) is relative degree 1 → `Wm` first-order is SPR → the **existing** law  
(`θ̇ = −Γ·P·B·e·Φ/denom`, `e = x − xm`) is already correct. Yaw needs only item 1 (1st-order type)  
and a validated `ref_model_bw` from a yaw closed-loop bandwidth measurement.

## Rollout (safety-staged, shadow mode throughout until the last step)

1.  Per-axis `ref_model_type` (item 1), keep all axes at passthrough `0`. No behaviour change. ✅ low risk
2.  Switch roll/pitch to 2nd-order `2`, yaw to 1st-order `1`, **injection still OFF**. Verify `xm`  
    tracks `r` cleanly in telemetry and `e = x − xm` stays bounded across a flight.
3.  Add augmented error for roll/pitch (item 3), injection still OFF. Verify `θ` converges / stays  
    bounded (projection + σ-mod already on).
4.  Enable `output_injection_on` per axis, one axis at a time, RC dead-man ready.

## Consequences

*   **+** Controller structure finally matches the identified plant relative degrees; the adaptive law  
    is provably stable for roll/pitch instead of relying on the small-`wn` throttle (ADR-0003) to mask  
    the relative-degree-2 SPR violation.
*   **+** Yaw gets the correct (simplest) treatment for free.
*   **−** Per-axis state growth (`MAX_NUM_BASIS` filtered-regressor floats × 2 axes) and a CMD `0x13`  
    signature change (GS must send axis index) — bump `GS_PROTO_VERSION`.
*   **Open:** yaw `ref_model_bw` still needs a closed-loop measurement; Z axis not identified (ADR-0004 #1).
