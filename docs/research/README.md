# Research Topics

This project spans the following technical domains:

- STM32F4 embedded firmware architecture and peripheral integration.
- FreeRTOS multi-rate task scheduling for flight control.
- IMU sensor fusion (Mahony filter) and attitude estimation.
- UAV control loops (PID and MRAC adaptive control integration).
- Ground-station binary protocol design (command and telemetry framing, CRC behavior).
- Safety and authority management (RC failover, arming/disarming, dangerous stop behavior).
- Autonomous path behaviors (target point, sinusoidal path, circular path).
- Python ground-station communication bridge (serial parsing, UDP mirroring, VOFA streaming).
