Motor PWM is generated by TIM3 and written through macro-mapped CCR registers. Initialization entry is `void PWM_TIM3_Init(void)` (`BSP/pwm.c:23`), called during board bring-up in `BSP_Init()` (`BSP/BSP.c:9`).

## TIM3 Frequency Configuration

In `PWM_TIM3_Init`:
- APB1 clock enabled for TIM3 (`BSP/pwm.c:33`)
- `TIM_Prescaler = 42-1` (`BSP/pwm.c:60`)
- `TIM_Period = 10000-1` (`BSP/pwm.c:59`)

With configured timer clock path, comments state 2 MHz timer tick and period 10000 counts, giving 200 Hz PWM (`BSP/pwm.c:59-60`). This is the ESC update frequency used by motor channels.

## Channel GPIO Mapping

TIM3 outputs are mapped as:
- PA6 -> TIM3 CH1 (`BSP/pwm.c:44`)
- PA7 -> TIM3 CH2 (`BSP/pwm.c:45`)
- PB0 -> TIM3 CH3 (`BSP/pwm.c:55`)
- PB1 -> TIM3 CH4 (`BSP/pwm.c:56`)

Logical motor macros then map to CCR registers:
- `M1 = TIM3->CCR1` (`BSP/pwm.h:8`)
- `M4 = TIM3->CCR2` (`BSP/pwm.h:9`)
- `M2 = TIM3->CCR3` (`BSP/pwm.h:10`)
- `M3 = TIM3->CCR4` (`BSP/pwm.h:11`)

This non-linear naming is intentional and must stay aligned with [[Motor Mixer]] sign/channel assumptions.

## PWM Range and ESC Contract

Motor command range constants:
- `Motor_PWM_ZERO = 2000` (`BSP/pwm.h:13`)
- `Motor_PWM_IDLE = 2150` (`BSP/pwm.h:14`)
- `Motor_PWM_MAX = 4000` (`BSP/pwm.h:15`)

`Set_PWM_Motors()` clamps each `mymotor.motorN` into `[ZERO, MAX]` via `value_limit` and writes CCRs (`BSP/pwm.c:274-284`). This count-space range represents the ESC command domain used by the mixer.

## Initialization and Safety State

After TIM3 setup, code explicitly initializes outputs to zero via `Set_Zero_Motors()` (`BSP/pwm.c:102`). This is the startup safety default before arming.

Runtime safety transitions:
- `Set_Zero_Motors()` forces all CCR channels to `Motor_PWM_ZERO` (`BSP/pwm.c:288-294`)
- `Set_IDLE_Motors()` sets all channels to idle spin threshold (`BSP/pwm.c:296-302`)

These are selected by [[StabilizerTask]] arm/mode guards (`TASK/StabilizerTask.c:170-205`).

## Related Timers

`pwm.c` also configures:
- TIM2 (`PWM_TIM2_Init`) for additional outputs (`BSP/pwm.c:110`)
- TIM4 (`PWM_TIM4_Init`) primarily for servo/beeper channels (`BSP/pwm.c:194,304`)

But motor propulsion path for quad ESC output is TIM3 + `M1..M4`.
